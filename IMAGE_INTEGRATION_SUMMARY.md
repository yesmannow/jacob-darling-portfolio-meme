## **💡 Adding More Images**

### **Want to add more design work?**
1. Add image to `/public/images/design/`
2. Update the `designPortfolio` array in `src/pages/Design.tsx`
3. Add: `{ id, src, title, category, description }`

### **Want to add more photography?**
1. Add image to `/public/images/photography/`
2. Update the `photoGallery` array in `src/pages/Photography.tsx`
3. Add: `{ id, src, title, category, description }`

### **Want to add more client logos?**
1. Add logo to `/public/images/logos/`
2. Update `clientLogos` array in `src/components/clients/ClientLogos.tsx`
3. Add: `{ name, src }`
